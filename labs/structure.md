This markdown document provides the required evidence for each lab that is built

Each lab's markdown must follow the following structure:


1. Prediction
    Explain expected frame/packet
    Identify network and network devices state

2. Independent Implementation

    Build topology on CML
    Administer network devices to the required behaviour 

3. Observation

    inspect device state
    capture packet/frames where necessary
    note command used and output

4. Mechanical explanation

examples:

    which device are involved in receiving and sending frames/packet
    what fields are to be inspected
    table/state being consulted
    decision that is made by the device
    which headers are modified
    what remains unchanged?
    what is the next hop?

5. Failure injection

    introduce a realistic fault into the relevant lab

6. Troubleshooting

    Observation
    Hypothesis
    Test
    Gather evidence
    Define root cause

7. Recovery 

    Implement remediation  
    Restored expected behaviour 
    Implement preventative measures

8. Verification 

    Confirm devices are behaving as expected by using appropriate commands adn packet captures

9. Documentation

    Note down: predictions, topology, implementation, evidence, failure, diagnosis, recovery and lessons learned.

10. Technical defense 

    Answer adversarial questions without relying on README
